## 2026/05/06
### Google Marketing Live 2026：データを意思決定に変える時代へ

Googleは「Google Marketing Live 2026」を2026年5月20日に開催することを発表しました。今年のテーマは **「Turn your data into decisions（データを意思決定に変える）」**。AI時代におけるビジネス成長の鍵は、断片化したデータをいかに統合し、賢い意思決定につなげるかにあります。

#### 1. Data Manager の進化：データを「見える化」する

Googleは今後数か月以内に、**Data Manager に新しい「マップビュー」** を導入します。これにより、BigQuery、Google Drive、HubSpot、Shopify など、さまざまなプラットフォームから流れてくるデータを一目で把握できるようになります。

- Google広告、Google アナリティクス、Google マーケティング プラットフォームを横断したスナップショットを提供
- ノーコードで既存のタグをアップグレードし、データ収集を強化
- 店舗売上などの新しいシグナルを既存のタグと組み合わせ、より豊かな顧客像を構築

#### 2. Meridian GeoX：地理的なインクリメンタリティ測定

**Meridian GeoX** は、地理的な単位で広告の純増効果（インクリメンタリティ）を測定する新ツールです。

- オープンソースのコードベース上に構築
- 測定結果のシグナルは、GoogleのMMM（マーケティング・ミックス・モデル）である **Meridian** にシームレスに連携
- 今年後半からテスト開始予定

これにより、「広告がなかった場合と比べて、本当にどれだけ売上が増えたのか？」というマーケターが長年抱えてきた問いに、より確かな答えを提示できるようになります。

#### 3. Meridian Studio：エンタープライズ向け新プラットフォーム

**Meridian Studio** は、Google Cloud をベースにした新しいエンタープライズ向けプラットフォームです。

- 高度なチームが、大量のモデルを柔軟にカスタマイズ・管理可能
- 自社の最も豊富なシグナル群を活用したMMMの構築を支援

#### 4. Gemini アドバンテージで競争優位を

今回の基調講演でGoogleが繰り返し強調しているのが、**「Gemini アドバンテージ」** という概念です。AIを活用した広告キャンペーン、エージェント型コマース（Agentic Commerce）、そしてYouTubeにおける新時代のパフォーマンスなど、Geminiを軸とした広告体験の変革が中心テーマとなっています。

#### まとめ：マーケターに求められること

GML 2026のメッセージは明快です。

> **データを集めるだけでは不十分。データを「動かして」意思決定につなげる時代が来た。**

Data Manager でデータを統合し、Meridian GeoX / Studio で効果を厳密に測定し、Gemini で実行する。この3つを組み合わせることで、AI時代の成長サイクルが完成します。5月20日の本番キーノートで、さらなる詳細が明らかになるのが楽しみです。
